# Quickstart: 驗證猜數字遊戲

此文件為執行與驗證指南；介面細節見 [contracts/](./contracts/)，資料細節見 [data-model.md](./data-model.md)。

## 前置條件

- Python 3.11 或更新版本（`python3 --version`）
- pytest（僅測試需要）：`python3 -m pip install pytest`

## 執行遊戲

在儲存庫根目錄：

```bash
PYTHONPATH=src python3 -m guessing_game
```

## 執行測試

```bash
python3 -m pytest
```

預期：所有測試通過（`pyproject.toml` 已設定 `pythonpath = ["src"]`，不需另設環境變數）。

## 手動驗證情境

| # | 步驟 | 預期結果 | 對應需求 |
|---|------|----------|----------|
| 1 | 啟動遊戲 | 出現 `請輸入猜測（1-100）：`，日誌顯示 `新局開始` | FR-001、FR-003、FR-017 |
| 2 | 輸入 `50` | 顯示 `太大` 或 `太小`（若剛好猜中則顯示答對） | FR-004～FR-006 |
| 3 | 依提示以二分法逐步縮小範圍 | 至多 7 次有效猜測後顯示 `答對！你總共猜了 N 次。`，日誌顯示 `本局結束，總猜測次數：N` | FR-006、FR-010、SC-006 |
| 4 | 輸入 `abc`、`3.5`、`+5`、`007`、空白 | 顯示格式錯誤訊息，次數不增加 | FR-007、FR-009 |
| 5 | 輸入 `0`、`101`、`-5` | 顯示超出範圍訊息，次數不增加 | FR-008、FR-009 |
| 6 | 輸入 ` 42 `（前後有空白） | 視為有效猜測 `42` | FR-015 |
| 7 | 答對後輸入 `y` | 顯示 `請按 Enter 再玩，或輸入 n 離開。` 並重新詢問 | FR-016 |
| 8 | 答對後直接按 Enter | 開始新局，日誌再次顯示 `新局開始`，次數歸零 | FR-012、SC-007 |
| 9 | 答對後輸入 `n` 或 `N` | 顯示 `再見！`，日誌顯示 `玩家離開（原因：n）`，結束碼 0 | FR-013 |
| 10 | 猜測時按 Ctrl+C | 顯示 `已離開遊戲，再見！`，無堆疊追蹤，結束碼 0 | FR-014、SC-005 |
| 11 | 猜測時按 Ctrl+D | 同上 | FR-014、SC-005 |
| 12 | 「是否再玩」階段按 Ctrl+C 或 Ctrl+D | 同上 | FR-014 |
| 13 | 全程檢視畫面與日誌 | 日誌只出現三類事件，且從未出現秘密數字 | FR-002、FR-017 |

## 架構規則驗證

```bash
python3 -m pytest tests/unit/test_architecture.py
```

預期：通過，確認 `engine.py` 沒有 `input()`／`print()` 呼叫，也沒有匯入 `cli`（憲章原則 III）。

## 結束碼驗證（範例）

```bash
printf '\n' | PYTHONPATH=src python3 -m guessing_game; echo "exit=$?"
```

預期：以空白輸入開始（格式無效）後遇到輸入結束，顯示 `已離開遊戲，再見！`，`exit=0`。
